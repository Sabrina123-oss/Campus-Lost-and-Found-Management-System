# 🎓 CampusFind – Campus Lost and Found Management System

CampusFind is a web-based **Campus Lost and Found Management System** developed to help students report, search for, and claim lost or found items within a university campus.

## 📌 Project Overview

The system provides a centralized platform where students can:

* Report lost items
* Report found items
* Browse available lost and found items
* Submit claims for found items
* Track item status
* Receive notifications and updates

Administrators can manage reported items, users, and claims through an admin dashboard.

## ✨ Features

### 👩‍🎓 Student

* Student registration and login
* Report lost/found items
* View reported items
* Search and browse items
* Submit claims
* View notifications
* Track item status

### 👨‍💼 Admin

* Admin authentication
* Manage users
* Review reported items
* Approve or reject items
* Manage claims
* Monitor system activities
